# Valalia

Valalia builds products. This repository is the mother-company website.

## What this is

The house site above the specialist brands. Stores keep their names. Valalia carries the standard.

## Add a brand

Add a record to `content/brands.json`, then add its store page under `brands/<id>/`.

## Add a product

Add a record to `content/products.json`, then add its page under `products/<id>/`. A page does not own the copy. The record does.

## Not in this version

Checkout, accounts, file delivery, and payment. Those stay behind interfaces until the human gate opens.

## Deploy

`main` is the site. GitHub Pages serves this repository.
